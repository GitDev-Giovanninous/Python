# CALCULATOR

Hii everyone, I’d like to introduce my first real project. It is a scientific calculator. 
Below, you’ll find more information about the project and how to use it.

# FUNCTIONALITY

- Standard operations (+, -, x, :)
- Scientific operations (sin, cos, tan, etc.)
- Input Management
- Error Management

# HOW TO USE

To use it, you need to run the `main.py` file. You have two options for doing this:
- Click on the `main.py` file from within the folder; your IDE will launch, and then you simply need to run the file.
- Go to your computer's terminal and run:
`python main.py` (make sure there are no other files with the same name).

# FILE DESCRIPTIONS:

main.py - Contains the program startup.
scientific.py - Contains the scientific calculator mode.
standard.py - Contains the standard calculator mode.
scientific_operations.py - Contains the scientific operation functions.

# REQUIREMENTS:

Python 3.x, but it's better Python 3.14.
You don't have to install any libraries.
